
# 数学建模模拟赛2（2025年第六届华数杯数学建模竞赛C题）

## 项目状态

算是已经完成了前面三个小问

## 快速开始

1. 创建虚拟环境：
```bash
python -m venv .venv
```

2. 确保启动虚拟环境

3. 安装依赖：
```bash
pip install -r requirements.txt
```

4. 运行：
```bash
cd ..
python -i -m mcm_simulated2
```
